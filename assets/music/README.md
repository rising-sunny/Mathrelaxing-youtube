# assets/music

Las pistas del canal (Epidemic Sound) son licenciadas: **no se versionan**.
Dejá los `.wav` acá y los builds los encuentran solos, o apuntá a otra carpeta:

    set MATHRELAXING_MUSIC_DIR=C:\ruta\a\tus\pistas     :: Windows
    export MATHRELAXING_MUSIC_DIR=/ruta/a/tus/pistas    # Linux/macOS

El catálogo (clave → nombre de archivo) vive en `tools/music_library.py`.
